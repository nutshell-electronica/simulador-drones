# SANT·SIM — Simulador de drones

Simulador de vuelo en un único HTML para el módulo de Sistemas Aéreos No Tripulados (CE Drones).
Autor: José Luis Guerrero Marín · IES Politécnico Jesús Marín (Málaga).

- `index.html`: el simulador (funciona sin conexión).
- `SANT_SIM_fuentes.zip`: fuentes por módulos y `build.sh` para regenerarlo.
